# 🍔 Bill Splitter (โปรแกรมหารค่าอาหาร)

โปรแกรมสำหรับคำนวณและแบ่งจ่ายค่าอาหาร (Bill Splitter) พัฒนาขึ้นเพื่อช่วยให้การหารบิลค่าอาหารในกลุ่มเพื่อนเป็นเรื่องง่ายและแม่นยำขึ้น โดยรองรับการคำนวณ Service Charge ตามเปอร์เซ็นต์ที่เลือกได้

🔗 **ลิงก์เข้าใช้งานเว็บไซต์** [ https://github.com/Kittanay-08/Bill-Splitter.git]

## ⚙️ การทำงานของโปรแกรม
โปรแกรมมีการทำงานที่เรียบง่ายและตรงไปตรงมา ดังนี้:
1. **รับค่าข้อมูล (Input):** ผู้ใช้กรอก "ยอดรวมค่าอาหารทั้งหมด", "จำนวนคนที่จะหาร", และเลือก "เปอร์เซ็นต์ Service Charge" (0%, 5%, 10%, 15%)
2. **ประมวลผล (Process):** 
   - ระบบจะตรวจสอบ (Validation) ว่าตัวเลขที่กรอกต้องมากกว่า 0 
   - คำนวณหาค่า Service Charge ทั้งหมด
   - นำยอดอาหารและ Service Charge มาหารด้วยจำนวนคน
3. **แสดงผล (Output):** ระบบจะแสดงยอดที่แต่ละคนต้องจ่าย โดยแยกให้เห็นชัดเจนว่า เป็นค่าอาหารเท่าไหร่, ค่า Service Charge เท่าไหร่ และยอดรวมสุทธิที่ต้องโอนคือเท่าไหร่

## 🛠️ เทคโนโลยีที่ใช้
โปรแกรมนี้ยึดหลัก Separation of Concerns อย่างเคร่งครัด โดยแยกการทำงานออกเป็น 3 ส่วน:
- **HTML (`index.html`):** โครงสร้างของหน้าเว็บ (ไม่มีการใช้ inline style หรือ onclick)
- **CSS (`style.css`):** การตกแต่งหน้าตาให้สวยงามสไตล์ Glassmorphism
- **JavaScript (`script.js`):** ระบบคำนวณทางคณิตศาสตร์ และการจัดการ Event/DOM (ใช้ Template Literal ในการแสดงผล)
